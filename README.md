## Assignment Modules

### Day 1: Vectorized Numerical Analysis (`Day_01_NumPy/`)
- **`student_scores_dataset.csv`**: Multidimensional student assessment dataset.
- **`day1_analysis.py`**: NumPy implementation of vectorized statistical scoring, curved grading, and normalization.

### Day 2: Data Wrangling & Cleaning (`Day_02_Pandas/`)
- **`raw_customer_churn_dataset.csv`**: Uncleaned customer records with nulls, duplicates, and type mismatches.
- **`day2_cleaning.ipynb`**: End-to-end data auditing, imputation, deduplication, and schema standardization pipeline.

### Day 3: Exploratory Data Analysis & Visualizations (`Day_03_Visualizations/`)
- **`retail_sales_visualization_dataset.csv`**: Transactional sales data with 10 feature attributes.
- **`day3_visualizations.py`**: Automated chart rendering script generating high-resolution figures.
- **`day3_eda_visualizations.ipynb`**: 5 core visualizations (Distribution, Comparison, Relationship, Correlation Heatmap, Trend) with markdown interpretations.
- **`findings_report.md`**: Executive summary covering key analytical findings, strategic recommendations, and limitations.
- **`weekly_sales_trend.png`**: High-resolution 300 DPI chart export generated via `plt.savefig()`. ring the 4-Day Data Science Bootcamp.
